📘 How to Answer Each Task 1 Type

Structure and paragraphing for every visual type

📈 Line Graph

Show trends over time. Group data by similarity, not by listing every year.

Intro → Overview: 2 main trends → Body 1: rising → Body 2: falling/stable

📊 Bar Chart

Compare categories. Highlight the highest, lowest, and any surprising result.

Intro → Overview: 2 key contrasts → Body 1: top → Body 2: bottom

🥧 Pie Chart

Focus on proportions. Note the largest and smallest slices.

Intro → Overview: biggest & smallest → Body 1: dominant → Body 2: smaller

📋 Table

Do not describe every cell. Group rows or columns with similar patterns.

Intro → Overview: 2 patterns → Body 1: highest → Body 2: lowest

🗺️ Map / Plan

Present tense for "now", future/passive for "planned". Describe location changes.

Intro → Overview: 2 biggest changes → Body 1: north/east → Body 2: south/west

⚙️ Process Diagram

Describe stages in order. Use passive voice and sequencing words.

Intro → Overview: X stages → Body 1: first half → Body 2: second half

🔀 Mixed Visuals

Cover both visuals. Link them explicitly.

Intro → Overview: 2 findings → Body 1: visual A → Body 2: visual B
💡

Universal Task 1 principles

  • Word count: 150+ words (aim for 160–190).
  • No opinions: describe what you see. Do not explain causes.
  • Overview is essential: missing it caps you at Band 5.
  • Time: 20 minutes max — 3 min plan, 15 min write, 2 min check.
